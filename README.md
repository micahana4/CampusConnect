# CampusConnect

## Short Description

CampusConnect is a web-based campus information and event management system developed for Palawan State University (PSU). It allows users to explore campus events, organizations, categories, venues, and campus locations in one platform.

The system also provides interactive maps and weather forecasts to help users locate venues and plan outdoor activities.

## Features

- *Event Management* – Create, view, update, and delete campus events.
- *Category Management* – Organize events according to categories.
- *Organization Management* – Manage campus organizations and view their associated events.
- *Venue Management* – Manage campus venues and view their locations.
- *Campus Management* – Manage campus information and view related events.
- *Student and Registration Management* – Manage student records and event registrations.
- *Interactive Maps* – Display campus and venue locations using Leaflet.js and OpenStreetMap.
- *Weather Forecast* – Display three-day weather forecasts using the Open-Meteo API.
- *Google Authentication* – Allow users to sign in using their Google accounts.
- *RESTful API* – Provide API endpoints for accessing system records.

## Technology Stack

- *Backend:* Python, Django
- *Frontend:* HTML, CSS, JavaScript
- *Database:* SQLite
- *API:* Django REST Framework
- *Authentication:* Django Allauth, Google OAuth
- *Maps:* Leaflet.js, OpenStreetMap
- *Weather API:* Open-Meteo
- *Development Tools:* Visual Studio Code, Git, GitHub
- *Deployment:* PythonAnywhere
